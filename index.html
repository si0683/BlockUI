// get started

Two lines, then just HTML

No framework to learn, no build step, no JavaScript for menus, dialogs or carts. Write semantic HTML with bui-* classes — the library does the rest.

  1. 1
    Add two lines

    The CSS and the script from the CDN.

  2. 2
    Stack the blocks

    Hero, products, reviews, pricing, FAQ, contacts, map.

  3. 3
    Pick a style and colour

    One line: BlockUI.start({ style, color }).

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/si0683/LightWebsiteUi@2.0.0/blockui.css">
<script src="https://cdn.jsdelivr.net/gh/si0683/LightWebsiteUi@2.0.0/blockui.js"></script>

<section class="bui-hero">
  <div class="bui-container">
    <div>
      <span class="bui-badge">Since 2012</span>
      <h1 data-name>Margherita</h1>
      <p>Wood-fired pizza, delivered hot.</p>
      <button class="bui-btn" data-open="order">Order now</button>
    </div>
    <img data-photo="pizza" alt="Pizza">
  </div>
</section>

<div class="bui-product">
  <div class="bui-product-image"><img data-photo="pizza 2"></div>
  <div class="bui-product-body">
    <h3>Pepperoni</h3>
    <button class="bui-btn" data-add="Pepperoni" data-price="12">Add</button>
  </div>
</div>

<div data-map="London, Covent Garden" data-label="We are here"></div>
// One object configures the whole site
const CONFIG = {
  name: 'Margherita',
  style: 'cozy',      // clean, bright, dark, modern, cozy
  color: 'red',       // 11 colours or any '#hex'
  lang: 'en',         // 'en' or 'ru'
  rain: '🍕',         // emoji rain on the first visit
  thanks: 'Thanks! We will call you back in 5 minutes.'
};

BlockUI.start(CONFIG);

// features

Everything a landing page needs

Each feature is a class or an attribute. Heavy parts load only when the page uses them.

🎨

Styles & colours

5 complete styles × 11 colours or any hex — fonts, shadows and shapes included.

📸

Photos by keyword

data-photo="pizza" — 68 topics of free Unsplash photos, no hunting for links.

🛒

Cart & orders

data-add and data-open — the cart and the order dialog build themselves.

📝

Forms

Floating labels, validation, a thank-you toast and confetti.

🎠

Sliders

Wrap any cards in .bui-slider — Swiper loads on demand.

🗺️

Maps

data-map="address" — OpenStreetMap with a marker, no API key.

✨

Icons & avatars

200,000+ Iconify icons (Material, Lucide, Tabler…) and DiceBear avatars from a name.

🌊

Tailwind mode

Design with Tailwind + daisyUI and keep LightWebsiteUi's behaviour.

🔷

i18n & types

English and Russian texts, TypeScript types, an ES module, SSR-safe.
