Get started

Two lines, then just HTML

CDN for CodePen and static sites, npm for bundlers. TypeScript types included.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/si0683/BlockUI@2.0.0/blockui.css">
<script src="https://cdn.jsdelivr.net/gh/si0683/BlockUI@2.0.0/blockui.js"></script>

<section class="bui-hero">
  <div class="bui-container">
    <div>
      <h1 data-name>Margherita</h1>
      <button class="bui-btn" data-open="order">Order</button>
    </div>
    <img data-photo="pizza">
  </div>
</section>
npm install blockuijs

import BlockUI from 'blockuijs';
import 'blockuijs/blockui.css';

BlockUI.start({
  name: 'Margherita',
  style: 'cozy',     // clean, bright, dark, modern, cozy
  color: 'red',      // 11 colours or any #hex
  rain: '🍕'
});
Features

Everything a landing page needs

Styles & colours

5 complete styles × 11 colours or any hex — fonts, shadows and shapes included.

Photos by keyword

data-photo="pizza" — 68 topics of free Unsplash photos.

Cart & orders

data-add and data-open — the cart and order dialog build themselves.

Forms

Floating labels, validation, thank-you toast and confetti.

Sliders

Wrap any cards in .bui-slider — Swiper loads on demand.

Maps

data-map="address" — OpenStreetMap with a marker, no API key.

Icons & avatars

200,000+ Iconify icons and DiceBear avatars from a name.

Tailwind mode

Design with Tailwind + daisyUI, keep BlockUI's behaviour.

i18n & types

English and Russian texts, TypeScript types, ES module, SSR-safe.

Playground

Switch this page's style and colour
