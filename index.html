LightWebsiteUi
GitHub

Стек для сайта одной командой

Astro + React + Tailwind CSS + shadcn/ui + Lucide — команда создаёт папку с проектом и сама ставит все пакеты.

  1. Установите Node.js 22.12 или новее Проверить: node -v
  2. Создайте проект
    npm create lightwebsiteui@latest my-site
  3. Запустите
    cd my-site && npm run dev

Сайт откроется на http://localhost:4321. Пока пакета нет в npm, вместо шага 2: npx github:si0683/LightWebsiteUi my-site

Что установится

Astro 7страницы и сборка
React 19интерактивные компоненты
Tailwind CSS 4стили классами
shadcn/ui19 компонентов; ещё — npx shadcn@latest add calendar
Lucideиконки: import { HeartIcon } from "lucide-react"
TypeScriptплюс ESLint и Prettier

Команды

npm run devразработка
npm run buildготовый сайт в папке dist/
