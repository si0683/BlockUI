Для кого

Когда сайт нужен быстро и надолго

Один лендинг вместо месяца разработки и абонентской платы конструктору.

Малый и средний бизнес

Сайт услуги, магазина или производства: цены, примеры работ, заявки и контакты с картой.

Веб-студии и фрилансеры

Типовые блоки собраны и проверены — время уходит на тексты и дизайн клиента, а не на вёрстку слайдеров.

Маркетологи

Посадочные страницы под рекламные кампании за вечер, без очереди в разработку.

Обучение

Чистый HTML без сборки: удобно учить вёрстку и показывать результат сразу в браузере.

Возможности

Всё, что нужно лендингу компании

Каждая функция — это класс или атрибут в HTML. Тяжёлые части загружаются, только если страница их использует.

Фирменный стиль

5 готовых стилей и 11 цветов или любой цвет бренда. Свой CSS всегда сильнее библиотеки.

Корзина и заявки

Кнопки «В корзину» и «Заказать» — корзина и окно заявки появляются сами.

Формы с проверкой

Имя, телефон, почта проверяются в браузере. Подключите свою CRM одним запросом.

Карта без ключа API

OpenStreetMap с меткой по адресу или координатам — без регистрации и оплаты.

Отзывы и галереи

Слайдер отзывов, галерея работ с увеличением фото, счётчики и таймер акции.

Фото и иконки

270 фотографий по ключевому слову, 200 000+ иконок и аватары по имени.

Светлая и тёмная тема

Переключатель темы в шапке и мобильное меню добавляются автоматически.

Русский и английский

Все тексты интерфейса на русском или английском, любую надпись можно заменить.

Для разработчиков

npm-пакет, типы TypeScript, режим Tailwind + daisyUI, поддержка Next.js и Astro.

Как начать

Три шага до готового сайта

Подключите библиотеку

Две строки в HTML — с CDN, без установки. Или npm install lightwebsiteui.

Соберите страницу из блоков

Главный экран, услуги, цены, отзывы, вопросы, контакты — классы bui-*.

Опубликуйте

Любой хостинг или GitHub Pages: это обычные статические файлы.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/si0683/LightWebsiteUi@3.2.1/lightwebsiteui.css">
<script src="https://cdn.jsdelivr.net/gh/si0683/LightWebsiteUi@3.2.1/lightwebsiteui.js"></script>

<section class="bui-hero">
  <div class="bui-container">
    <div>
      <h1>Ремонт квартир под ключ</h1>
      <p>Гарантия 3 года, оплата по этапам.</p>
      <button class="bui-btn" data-open="order">Вызвать сметчика</button>
    </div>
    <div class="bui-hero-picture"><img src="img/hero.jpg"></div>
  </div>
</section>

<div data-map="53.22217, 50.24484" data-label="Мы здесь"></div>
// Все настройки сайта — в одном объекте
const CONFIG = {
  name: 'Мастер в ремонте',
  style: 'modern',     // clean, bright, dark, modern, cozy
  color: 'orange',     // 11 цветов или '#hex' бренда
  lang: 'ru',
  thanks: 'Спасибо! Перезвоним в течение дня.'
};

LightWebsiteUi.start(CONFIG);

Вопросы

Частые вопросы

Это бесплатно? Можно для коммерческих проектов?

Да. Библиотека распространяется по лицензии MIT: используйте её в любых проектах, в том числе для клиентов, без отчислений.

Чем это лучше конструктора сайтов?

Нет абонентской платы и привязки к платформе: сайт — это ваши файлы, их можно разместить где угодно и передать клиенту. При этом не нужно писать вёрстку с нуля.

Куда уходят заявки с форм?

Библиотека проверяет форму и показывает благодарность в браузере. Чтобы заявки попадали в почту, Telegram или CRM, добавьте свой запрос fetch или сервис форм.

Можно ли сделать фирменный дизайн?

Да. Задайте цвет бренда в color, а любые правила — в своём CSS: они всегда сильнее стилей библиотеки. Для полной свободы есть режим Tailwind + daisyUI.

Нужен ли сервер и сборка?

Нет. Это статические файлы: подойдёт любой хостинг, GitHub Pages или ваш сервер. Для Next.js и Astro есть npm-пакет и примеры.

Что будет при обновлении библиотеки?

Каждая версия закреплена в ссылке (@3.2.1) и не меняется. Ваш сайт обновится, только когда вы сами поменяете номер версии.
