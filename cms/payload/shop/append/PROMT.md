
## 13. Магазин

Проект создан с магазином (`--shop`). Прочитай `SHOP.md`.

- **Что продаём:** «категории и примеры товаров»
- **Карточка товара:** «какие характеристики, фото, варианты (размер, цвет)»
- **Доставка:** «самовывоз / курьер / СДЭК / Почта России; стоимость»
- **Оплата:** [ ] онлайн (`--pay`) [ ] при получении [ ] счёт для юрлиц
- **Учёт:** [ ] товары вручную в админке [ ] из 1С (`--1c`) [ ] из МойСклад
- **Уведомления о заказе:** «e-mail / Telegram менеджеру / SMS покупателю»

Цены и остатки бери только из CMS, корзина в браузере — только для показа.
