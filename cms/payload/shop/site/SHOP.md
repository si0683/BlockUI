# Магазин

Проект создан с `--shop`: каталог товаров, карточки, корзина и заказы. Всё хранится в Payload (`cms/`), раздел админки «Магазин».

## Что есть

| Где                                   | Что                                                                                                             |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Админка → Магазин → Категории         | группы товаров, можно вложенные (поле «Родительская категория»)                                                 |
| Админка → Магазин → Товары            | название, артикул, категория, цена, старая цена, остаток, фото, описание, характеристики, «Показывать на сайте» |
| Админка → Магазин → Заказы магазина   | состав, сумма, покупатель, адрес, статус: новый → оплачен → в работе → отгружен → выполнен / отменён            |
| `/catalog/` и `/catalog/<категория>/` | каталог с фильтром по категориям (товары подкатегорий тоже показываются)                                        |
| `/product/<адрес>/`                   | карточка товара: фото, цена, наличие, характеристики, «В корзину»                                               |
| `/cart/`                              | корзина и оформление заказа                                                                                     |
| `/order/?order=…`                     | страница заказа: статус, состав, сумма                                                                          |

Адрес товара или категории (`slug`) делается из названия транслитерацией. Его можно поменять в админке.

## Как проходит заказ

1. Корзина хранится в браузере (localStorage). Цены в ней — только для показа.
2. «Оформить заказ» отправляет `POST /api/shop-orders/checkout`: товары, количество и контакты. CMS заново берёт цены и остатки из базы, проверяет наличие, создаёт заказ и сразу уменьшает остаток.
3. **С онлайн-оплатой (`--pay`)** покупатель уходит на страницу оплаты. После неё он возвращается на `/order/`, статус проверяется через API провайдера — так же, как у тарифов (см. `PAYMENTS.md`).
4. **Без онлайн-оплаты** покупатель сразу видит «Заказ принят», а менеджер обрабатывает заказ в админке.

Заказы создаются только через `/checkout`. Читать и менять их могут только пользователи админки.

## Как менять

- Внешний вид: `src/components/shop/*` (карточка, каталог, корзина, страница заказа), `src/layouts/shop.astro` (шапка магазина).
- Данные для страниц: `src/data/shop.ts` (REST API Payload).
- Поля товара: `cms/src/collections/Products.ts`. После изменения выполните `cd cms && npm run generate:types` и поправьте `src/data/shop.ts`.
- Демо-товары создаются при первом запуске пустой базы (`cms/src/addons/shop.ts`). Удалите их в админке или загрузите каталог из 1С (`--1c`).

## Статический сайт

Каталог и карточки собираются в HTML при `npm run build` — с товарами, ценами и остатками на момент сборки. Корзина и заказ работают в браузере всегда, а при оформлении CMS проверяет актуальные цены и наличие. Чтобы витрина обновлялась сама, пересобирайте сайт по расписанию или после изменений (см. `PAYLOAD.md`) либо переведите сайт в серверный режим Astro.
