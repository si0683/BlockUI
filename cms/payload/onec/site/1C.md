# Обмен с 1С

Проект создан с `--1c`: магазин обменивается данными с 1С по стандартному протоколу CommerceML («Обмен с сайтом»). Он есть в 1С:Управление торговлей, Комплексной автоматизации, ERP, УНФ и Рознице.

| Из 1С на сайт                             | С сайта в 1С                                             |
| ----------------------------------------- | -------------------------------------------------------- |
| группы → категории (с вложенностью)       | новые заказы: состав, сумма, покупатель, телефон, e-mail |
| товары: название, артикул, описание, фото | статус оплаты (если подключена `--pay`)                  |
| свойства → «Характеристики» товара        |                                                          |
| цены (выбранный тип цен) и остатки        |                                                          |
| статусы заказов: оплачен, отгружен, отменён |                                                        |

## Настройка

1. Логин и пароль обмена — в `cms/.env`: `ONEC_LOGIN` и `ONEC_PASSWORD` (пароль установщик сгенерировал сам). Без них обмен не работает.
2. Тип цен: `ONEC_PRICE_TYPE=Розничная` — точное название из 1С. Пусто — берётся первый тип из выгрузки. `ONEC_OLD_PRICE_TYPE` — необязательный тип цен для зачёркнутой «старой цены».
3. В 1С: «Администрирование → Интеграция с другими программами → Обмен с сайтами» (название зависит от конфигурации) → создать узел обмена:
   - адрес сайта: `https://cms.ваш-сайт/api/1c/exchange` (локально: `http://localhost:3000/api/1c/exchange` — 1С должна видеть этот адрес);
   - пользователь и пароль — из `cms/.env`;
   - выгружать: товары, цены, остатки; обмен заказами — включить;
   - упаковку в zip-архив — **выключить**.
4. Запустите обмен в 1С. Ход и ошибки — в админке: «Магазин → Обмен с 1С».

## Как устроено

1С сама обращается к CMS — открывать порты 1С не нужно.

- **Каталог:** `checkauth` → `init` → `file` (import.xml, offers.xml, картинки) → `import` для каждого файла. Большие файлы загружаются частями: на каждый запрос `import` обрабатывается `ONEC_BATCH` товаров (по умолчанию 100), 1С повторяет запрос, пока не получит `success`.
- **Заказы:** `checkauth` → `init` → `file` (изменения заказов из 1С) → `query` (новые заказы с сайта) → `success` (заказы отмечаются как выгруженные, поле «Выгружен в 1С»).
- Файлы обмена лежат в `cms/.1c-exchange/` (в git не попадают). Каждая выгрузка каталога начинается с чистой папки.
- Товары и категории связаны с 1С по полю «Ид в 1С» (`externalId`). Товары без него (созданные вручную) обмен не трогает.

## Правила

- **Видимостью товаров из 1С управляет 1С.** Новый товар скрыт, пока не придёт его цена. С ценой больше нуля он показывается, с нулевой — скрывается. Товар с пометкой удаления в 1С скрывается.
- **Полная выгрузка** (в 1С не стоит «только изменения»): товары из 1С, которых не было в выгрузке, скрываются. Ручные товары остаются.
- **Остатки:** сумма по всем складам. Сайт уменьшает остаток при заказе, следующий обмен перезаписывает его данными из 1С.
- **Характеристики (размер, цвет):** предложения вида `товар#характеристика` объединяются в один товар — минимальная цена и общий остаток. Варианты в корзине пока не поддерживаются.
- **Фото** загружаются в «Файлы» один раз. Повторно — только если в 1С изменился список картинок.
- **Статусы из 1С:** «Отменен» → отменён, «Дата отгрузки» или «Финальный статус» → отгружен, «Дата оплаты» или «Заказ оплачен» → оплачен.
- Обмен работает в кодировках UTF-8 и windows-1251.

## Проверка без 1С

Протокол можно пройти вручную через `curl` (логин и пароль — из `cms/.env`):

```bash
curl -u 1c:ПАРОЛЬ "http://localhost:3000/api/1c/exchange?type=catalog&mode=checkauth"
```

Ответ: `success`, имя cookie и её значение. Дальше передавайте cookie (`-b onec_session=…`) или снова `-u`:

```bash
curl -u 1c:ПАРОЛЬ "http://localhost:3000/api/1c/exchange?type=catalog&mode=init"
curl -u 1c:ПАРОЛЬ --data-binary @import.xml "http://localhost:3000/api/1c/exchange?type=catalog&mode=file&filename=import.xml"
curl -u 1c:ПАРОЛЬ "http://localhost:3000/api/1c/exchange?type=catalog&mode=import&filename=import.xml"
curl -u 1c:ПАРОЛЬ "http://localhost:3000/api/1c/exchange?type=sale&mode=query"
```

Повторяйте `mode=import`, пока ответ `progress`.

## Где код

- `cms/src/addons/integrations.ts` — эндпоинт `/api/1c/exchange` и коллекция «Обмен с 1С».
- `cms/src/onec/exchange.ts` — протокол (шаги `checkauth`, `init`, `file`, `import`, `query`, `success`).
- `cms/src/onec/catalog.ts` — загрузка import.xml и offers.xml (а также prices/rests в пакетном режиме).
- `cms/src/onec/sale.ts` — выгрузка заказов и приём их статусов.
- `cms/src/onec/auth.ts`, `storage.ts`, `xml.ts` — вход, файлы обмена, разбор XML.
