
## 10. CMS: Payload

Проект создан с Payload CMS (`--cms=payload`). Прочитай `PAYLOAD.md`. Контент и заявки — в `cms/`, сайт берёт данные через `src/data/content.ts`.

- **Что редактируется в админке:** «тексты страниц, услуги, цены, отзывы, вопросы, новости, товары…»
- **Новые коллекции:** «например: Новости (заголовок, дата, обложка, текст), Товары (название, цена, фото, категория)»
- **Кто работает в админке:** «только я / менеджеры — роли и права»
- **Заявки:** куда ещё уведомлять: «Telegram / e-mail / CRM / только админка»
- **База данных:** [ ] SQLite (как создано по умолчанию) [ ] PostgreSQL
- **Обновление сайта после правок:** [ ] пересборка вручную [ ] автоматически (вебхук) [ ] серверный режим Astro

Структуру данных меняй в `cms/src/collections`, затем обнови `src/data/content.ts` и типы (`cd cms && npm run generate:types`).
