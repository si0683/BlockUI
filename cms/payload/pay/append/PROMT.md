
## 11. Онлайн-оплата

Проект создан с онлайн-оплатой (`--pay`). Прочитай `PAYMENTS.md`.

- **Что продаём:** «тарифы как в шаблоне / товары / подписку / запись на услугу / предоплату»
- **Цены:** «фиксированные / от количества / промокоды и скидки»
- **После оплаты:** «письмо покупателю / уведомление в Telegram / доступ в личный кабинет / ссылка на скачивание»
- **Чеки 54-ФЗ:** [ ] не нужны [ ] нужны (ЮKassa: «Чеки от ЮKassa», ставка НДС: «…»)
- **Возвраты:** «вручную в личном кабинете провайдера / кнопкой в админке»

Цену бери только из CMS, статус оплаты — только из API провайдера. Ключи — только в `cms/.env`.
