# Онлайн-оплата: ЮKassa

Проект создан с `--pay=yookassa`. Покупатель оплачивает тариф на сайте и возвращается на страницу «Спасибо». Заказ появляется в админке, раздел «Заказы».

## Как это работает

1. На тарифе с заполненным полем **«Сумма для онлайн-оплаты»** (админка → Тарифы) появляется кнопка «Оплатить». Тарифы без суммы («от 90 000 ₽») открывают обычную форму заявки.
2. Сайт отправляет `POST /api/orders/pay` (`src/lib/payments.ts`). CMS берёт цену из тарифа (из браузера цену подменить нельзя), создаёт заказ и платёж в ЮKassa и возвращает ссылку на страницу оплаты.
3. После оплаты ЮKassa возвращает покупателя на `/thanks/?order=…`. Страница спрашивает статус у CMS, а CMS сверяет его с ЮKassa.
4. ЮKassa присылает уведомление на `/api/orders/webhook`. CMS не доверяет телу уведомления и перечитывает статус платежа через API. Заказ становится «Оплачен».

Код: `cms/src/collections/Orders.ts` (заказы и эндпоинты), `cms/src/payments/provider.ts` (ЮKassa), `src/components/site/pay-dialog.tsx`, `src/pages/thanks.astro`.

## Тестовый режим

1. В [личном кабинете ЮKassa](https://yookassa.ru/my) создайте **тестовый магазин**.
2. Возьмите `shopId` и секретный ключ: «Интеграция» → «Ключи API», тестовый ключ начинается с `test_`. Пропишите их в `cms/.env`:
   ```
   YOOKASSA_SHOP_ID=123456
   YOOKASSA_SECRET_KEY=test_…
   ```
3. Перезапустите `npm run cms` и оплатите тариф тестовой картой из [документации ЮKassa](https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing). Деньги не списываются.

Без ключей кнопка «Оплатить» покажет «Оплата не настроена: укажите ключи в cms/.env».

## Уведомления (вебхук)

- В ЛК ЮKassa: «Интеграция» → «HTTP-уведомления».
- Адрес: `https://<адрес CMS>/api/orders/webhook`.
- События: `payment.succeeded` и `payment.canceled`.
- Локально ЮKassa до `localhost` не достучится. Это не мешает проверке: страница «Спасибо» сама спрашивает статус у ЮKassa. Чтобы проверить именно вебхук, откройте CMS наружу туннелем: `npx cloudflared tunnel --url http://localhost:3000` или ngrok.

## Чеки (54-ФЗ)

Если подключены «Чеки от ЮKassa», включите отправку данных для чека:

```
YOOKASSA_RECEIPTS=true
YOOKASSA_VAT_CODE=1   # 1 — без НДС; коды ставок — в документации ЮKassa
```

Чек уйдёт на e-mail, который покупатель указал в форме оплаты.

## Боевой режим

1. Пройдите подключение магазина в ЮKassa и замените тестовые ключи на боевые в `cms/.env` на сервере.
2. Пропишите адрес вебхука для боевого магазина.
3. В `cms/.env` укажите адрес сайта: `SITE_URL=https://ваш-сайт` (несколько — через запятую). Возвращаться после оплаты можно только на эти адреса.
4. Проверьте одну реальную оплату на небольшую сумму и верните её в ЛК.

Ключи храните только в `cms/.env` на сервере, в репозиторий их не коммитить.
