
## Вход в админку с кодом (2FA)

Проект создан с `--2fa`: после пароля админка спрашивает шестизначный код из приложения-аутентификатора — Яндекс Ключ, Google Authenticator, Aegis, 1Password и т. п. Сделано плагином [payload-totp](https://github.com/GeorgeHulpoi/payload-totp), подключён в `cms/src/addons/security.ts`.

- **Подключить себе:** админка → ваш профиль (правый верхний угол) → поле «Приложение-аутентификатор» → «Настроить». Отсканируйте QR-код и введите код из приложения.
- **Обязательно для всех:** `TOTP_REQUIRED=true` в `cms/.env`. Тогда каждый пользователь сразу после входа настраивает приложение и без кода ничего в админке не видит. `false` — каждый включает 2FA сам.
- **Название в приложении:** `TOTP_ISSUER` в `cms/.env`.
- **Защита от перебора:** после `maxLoginAttempts` неверных кодов вход блокируется на `lockTime`, как при неверном пароле. Снять блок может другой пользователь — кнопкой Force Unlock в карточке пользователя.
- **Потеряли телефон:** снять 2FA в админке может только сам пользователь, своим кодом. При потере телефона на сервере выполните `cd cms && npm run reset-2fa -- почта@пользователя`. Затем пользователь входит по паролю и настраивает приложение заново.
- **Сайт не затронут.** Чтение контента и новые заявки остаются публичными: в коллекциях стоит `custom.totp.disableAccessWrapper` (`cms/src/access.ts`). Новой публичной коллекции поставьте такую же отметку, иначе анонимные запросы получат отказ.
- После обновления плагина на PostgreSQL или SQLite сделайте миграцию: `npm run payload migrate:create` и `npm run payload migrate`.
