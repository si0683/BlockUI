
## 12. Вход в админку с кодом (2FA)

Проект создан с 2FA для админки (`--2fa`, плагин payload-totp, см. `PAYLOAD.md`).

- **Обязательность:** [ ] каждый включает сам [ ] обязательно для всех (`TOTP_REQUIRED=true`)
- **Роли в админке:** «кто может снимать 2FA и разблокировать пользователей»

Новым публичным коллекциям ставь `custom.totp.disableAccessWrapper` (см. `cms/src/access.ts`), иначе сайт не сможет их читать.
